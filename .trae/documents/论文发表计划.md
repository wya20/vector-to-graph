## 五、与 Graphify 的关系（已明确）

### 5.1 Graphify 简介
Graphify（40k+ stars）是一个将代码库转化为知识图谱的开源工具。它使用 Tree-sitter 解析代码，通过 Leiden 算法进行社区检测。

### 5.2 差异化定位

| 方面 | Graphify | Vector-to-Graph |
|------|----------|-----------------|
| 核心功能 | 知识图谱构建 | 混合检索引擎 |
| 检索方式 | 纯图谱检索 | 向量+图谱双路检索 |
| 智能路由 | 无 | 有（自动判断查询类型） |
| 结果融合 | 无 | 有（加权排序） |
| AI 集成 | 通用 | MCP 专精（面向 AI 编码助手） |

### 5.3 论文中的表述
在 Related Work 部分明确说明：
> Vector-to-Graph differs from Graphify by focusing on hybrid retrieval with intelligent routing, rather than pure knowledge graph construction.

## 六、论文大纲

### 6.1 章节结构

```
1. Abstract（摘要）
   - 150-300 words
   - Problem, Method, Results

2. Introduction（引言）
   - Background
   - Problem Statement
   - Contributions
   - Paper Structure

3. Related Work（相关工作）
   - Vector Retrieval
   - Knowledge Graph Retrieval
   - Hybrid Retrieval Systems
   - Graphify and Similar Tools

4. System Design（系统设计）
   - Architecture Overview
   - Vector Retrieval Module
   - Graph Retrieval Module
   - Intelligent Routing Mechanism
   - Result Fusion Strategy

5. Implementation（实现）
   - Tech Stack
   - Key Components
   - Deployment

6. Experiments（实验）
   - Test Scenarios
   - Performance Comparison
   - Analysis

7. Conclusion and Future Work（结论与展望）
```

### 6.2 创新点总结

| 创新点 | 说明 |
|--------|------|
| 智能路由 | 自动判断查询类型，选择最优检索策略 |
| 混合融合 | 向量+图谱结果加权排序 |
| MCP 集成 | 面向 AI 编码助手的标准化集成 |
