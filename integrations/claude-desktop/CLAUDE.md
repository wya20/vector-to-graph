## Vector-to-Graph

This project uses Vector-to-Graph for hybrid search combining vector similarity and knowledge graph relationships.

Before answering code architecture or codebase questions:
1. Use `vtg_query` to search for relevant information
2. Use `vtg_get_graph` to explore code relationships
3. Cite sources with confidence scores

Tools:
- `vtg_index(path)`: Index a file or directory
- `vtg_query(question, limit)`: Query the hybrid search engine
- `vtg_get_graph()`: Get the knowledge graph structure
